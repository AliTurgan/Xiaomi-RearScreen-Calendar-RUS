# Карточка календаря для заднего экрана Xiaomi

<img width="1920" height="1080" alt="Xiaomi_RearScreen_Calendar_RUS" src="https://github.com/user-attachments/assets/41578613-faef-45a8-8f39-063cee11f42d" />
Модуль виджета календаря в уведомлениях Заднего экрана для REAREye.

## Оригинальное описание модуля с переводом на русский:
> 
> Это **виджет календаря, созданный на основе чистого кода** специально для Xiaomi MIUI / HyperOS Theme Engine (MAML). Он не содержит внешних графических ресурсов (No Assets), полностью полагаясь на системные переменные времени и чистые математические выражения для определения координат сетки.
> 
> Этот проект специально разработан для **серии Xiaomi 17 Pro и других моделей с задними экранами со специальным соотношением сторон (например, модели `q200` / `p2`)**, с пропорциональным масштабированием и адаптацией к избеганию безопасной зоны, а также идеально воспроизводит логику энергосбережения при отключении AOD на системном уровне.
> 
> ---
> 
> ## ✨ Основные функции
> 
> ### 🧮 1. Календарь без ресурсов (чисто математически выведенный)
> Полностью отказывается от традиционного метода наложения изображений. Используя выражения MAML, такие как `eq` и `ne`, в сочетании с алгоритмами `%` (по модулю) и `/7` (округление вниз):
> 
> - Автоматически вычисляет смещение дня недели для 1-го числа месяца
> 
> - Автоматически определяет високосные/обычные годы и количество дней в феврале
> 
> - Автоматически обрабатывает динамическое скрытие и отображение 29-го, 30-го и 31-го числа каждого месяца
> 
> - Автоматически вычисляет и выделяет координаты «сегодняшнего дня»
> 
> ### 📱 2. Динамическая безопасная зона и динамический отклик на уровне заднего экрана
> 
> Не просто жестко заданные координаты `1080p`! Код включает логику определения фактического соотношения сторон (`#view_width / #view_height`):
> 
> - Интеллектуально определяет, имеет ли текущая операционная среда соотношение сторон `q200` или `p2`.
> 
> - Динамически генерирует глобальный коэффициент масштабирования `#scale`.
> 
> - **Точное предотвращение попадания в кадр:** Левая базовая зона `103` обозначена как запретная зона; календарная сетка автоматически сжимается и плавно перемещается в правую безопасную зону для отображения.
> 
> ### 🔋 3. Логика энергосбережения AOD с нулевым кадром
> 
> Идеально сочетает элегантные анимации переходов с экстремальным энергосбережением для постоянно включенного OLED-дисплея:
> 
> - **Чисто черный фон для предотвращения выгорания:** Нижний слой использует чисто черный фон `#000000`; прозрачность верхнего интерфейса уменьшается до `150`, когда экран выключен.
> 
> - **Обратный вызов градиента Folme:** Использует системный движок Folme от Xiaomi для обработки анимаций переходов при постоянно включенном экране.
> 
> - **Убийца нулевых кадров:** В момент завершения анимации срабатывает функция обратного вызова (`onComplete`), выполняющая `<FrameRateCommand rate="0"/>` для полного приостановления работы движка и достижения нулевого энергопотребления. Экран мгновенно переключается на `30 FPS` для пробуждения при включении питания.
> 
> --
> 
> ## 🛠️ Расширенные настройки
> 
> ### Настройка положения заголовка «Год/Месяц» По умолчанию код выравнивает верхний левый угол «yyyy年M月» по левому краю первого столбца календаря (понедельник). Если вам нужно точно настроить его положение, измените значения координат `x` и `y` в теге `<DateTime>`:
> 
> ```xml
> <DateTime x="#grid_x - (6 * #scale)" y="(18 * #scale)" color="#FFFFFF" size="(18 * #scale)" bold="true" format="yyyy年M月" />
> ```


## 🧰 Изменения внесённые мною

### Календарь полностью русифицирован.
Так как я не смог просто добавить поддержку русского языка в модуль помимо других языков, я вырезал все языки, добавил русский язык, а также перевел значения в manifest.xml. Дни недели сместил с ВС-СБ на привычный нам всем ПН-ВС вручную. То есть, модуль отлично подойдет для людей их СНГ, но за пределами нет.

### Редизайн заднего фона плашки (На тёмную тему)
Мне не нравилась что при переходе на карточку задний фон становился белым. Так что я сделал фон заднего экрана и его AOD версию в стиле закреплённых сообщений на заднем экране. Теперь глазам хорошо.

## ➖ Недостатки с моей стороны

Размеры некоторых текстов я не изменил. Менял те, что попадались на глаза. Из-за того что изначальные китайские тексты меньше по длинне, пришлось уменьшать русские тексты. Тестировал на Xiaomi 17 Pro Max. Планирую немного увеличить всё содержимое чтобы адаптировать под экран Pro Max.
